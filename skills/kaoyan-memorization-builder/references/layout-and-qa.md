# Layout And Quality Gate

## Visual System

- Produce both a restrained color study edition and a black-and-white-compatible edition.
- Always print `A`, `B`, or `C` as text. Print `R` in a separate outlined marker. Do not rely on hue.
- Keep original chapter and point order. Use hierarchy, spacing, border weight, and labels to improve scanning.
- Use recall lines after a point only when active recall is useful; do not add empty decoration.
- Use `compact` for dense reference review, `standard` by default, and `spacious` for annotation-heavy study. Density changes type size, leading, and paragraph rhythm; it never changes content or order.

## Memory Structures

- Use a comparison table for genuinely repeated fields across two or more concepts.
- Use a process for ordered steps or causal stages.
- Use a timeline only when chronological position matters.
- Use a relationship structure for dependencies, contrasts, inclusions, or cause/effect links.
- Keep essential facts as selectable text. Images may support, not replace, source facts.

## Pagination

- Use A4 portrait and mirrored duplex margins.
- Keep a point title, A/B/C and R markers, and its first content fragment together.
- Keep captions with figures; avoid splitting small comparisons or processes.
- Size raster images from pixel dimensions at no less than 150 effective DPI, then reduce further when the maximum page width or height requires it. Never stretch a small image to a fixed page width.
- Generate a directory for multi-chapter material. PDF directory page numbers are authoritative; DOCX pagination may update independently.

## Blocking QA

Block delivery for changed exact definitions, reordered source content without target-specific authorization, changed source hashes, unlabeled AI text, missing evidence, unresolved review flags, missing formulas/glyphs, clipped text, nonembedded PDF fonts, empty pages, images below 150 effective DPI, unreadable graphics, incorrect directory text, chapter headings on the wrong PDF page, mismatched PDF bookmarks, or distinctions that disappear in grayscale.

Render and inspect every page. Structural extraction alone cannot detect overflow or bad page breaks. Verify that PDF text remains selectable and that required source labels appear.
