# Understanding And Diagnostic Workflow

## Explanation Material

Build explanations in this order:

1. Accurate core statement.
2. Connection to prerequisite knowledge.
3. Concrete example or analogy.
4. Positive example and counterexample.
5. Boundary conditions and common misconceptions.
6. Exam-style application.

Label generated analogies and explanations. Do not present them as quotations from the source.

## Diagnostic Ladder

Create questions across these levels:

1. Recall: state the concept accurately.
2. Discrimination: distinguish it from a nearby concept.
3. Explanation: explain why it works.
4. Application: solve a standard problem.
5. Transfer: handle a changed or unfamiliar context.
6. Error correction: identify and repair faulty reasoning.

## Outputs

- `practice`: diagnostic questions, confidence field, and response space.
- `answers`: reference answers, scoring rubric, misconceptions revealed by each wrong answer, and remediation advice.
- Generate both PDF and DOCX for both variants.

When the user later submits answers, evaluate against the rubric and optionally create a focused remediation sheet using the memorization workflow.
