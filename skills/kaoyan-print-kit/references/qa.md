# Final Quality Review

Inspect the source selections, JSON manifest, final PDF, DOCX, and every rendered page image. Keep the review read-only and report blocking findings first with file and page references.

Block delivery for any of these conditions:

- Incorrect, missing, or reordered source content.
- Missing or altered formulas, symbols, choices, or diagrams.
- Question-answer mismatch or answer leakage in a practice version.
- Unresolved OCR uncertainty.
- Missing Chinese glyphs, unreadable source labels, clipping, overlap, or bad page breaks.
- Weak black-and-white contrast or distinctions that depend on color alone.
- A PDF or DOCX variant that is missing or does not match the requested content.

Approve only after every page has been inspected and no blocking condition remains. Do not block on subjective style preferences unless they reduce readability or print usability.
