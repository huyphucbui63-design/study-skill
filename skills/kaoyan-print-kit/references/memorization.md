# Memorization Workflow

## Required Inputs

Collect subject, chapter, scope, content type, source authority, desired density, annotation space, and print profile.

## Content Types

- `formula`: formula, symbol meanings, conditions, common transformations, and common mistakes.
- `definition`: exact definition, keywords, boundaries, counterexamples, and recall cue.
- `theorem`: assumptions, conclusion, relationships, use cases, and traps.
- `timeline`: date, event, significance, and relation to adjacent events.
- `vocabulary`: term, meaning, usage, contrasts, and example.
- `mixed`: hierarchical outline, concise explanations, comparisons, and review prompts.

## Rules

1. Separate exact source wording from generated memory aids.
2. Keep pure formula or pure definition requests homogeneous; do not add unrelated prose.
3. Use an image block for formulas that cannot be transcribed with high confidence.
4. Default to one `study` version. Add a blank-recall version only when requested.
5. Preserve chapter numbering and source labels.
